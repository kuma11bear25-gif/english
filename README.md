# マイ英語文章帳

英語の勉強用に、自分だけの英語文章帳を作れるシンプルなWebアプリです。ビルド不要のHTML/CSS/JavaScriptだけで動きます。

## 機能

- 英語文章をメモできる（「日常表現」「慣用句」「その他」のカテゴリ分け付き）
- 保存した文章を音声で読み上げ（ブラウザのWeb Speech API）
- 入力した英語文章を自動で日本語訳（Google翻訳エンジンを優先使用し、会話的な言い回しを重視。失敗時はMyMemoryにフォールバック。手動編集も可）
- 一覧・フラッシュカードともにカテゴリで絞り込み可能
- フラッシュカード形式で学習できる
- フラッシュカードは「英語→日本語」「日本語→英語」を切り替え可能
- スマートフォン対応（レスポンシブデザイン、スワイプでカード切替、ホーム画面に追加してアプリのように使用可能、オフライン対応）

## 使い方

ビルドは不要です。`index.html` をブラウザで直接開くか、簡易サーバーで配信してください。

```bash
# 例: Pythonの簡易サーバーを使う場合
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

GitHub Pagesなどの静的ホスティングにもそのままデプロイできます。

### スマートフォンでの利用

スマートフォンのブラウザで開くと、レスポンシブなレイアウトで表示されます。さらに、以下の方法で「ホーム画面に追加」するとアプリのように起動できます。

- **iOS (Safari)**: 共有メニュー → 「ホーム画面に追加」
- **Android (Chrome)**: メニュー → 「ホーム画面に追加」/「アプリをインストール」

ホーム画面に追加すると、Service Workerによりオフラインでも一覧の閲覧やフラッシュカード学習ができます（翻訳機能はオンライン時のみ利用可能です）。

フラッシュカード画面では、カードをタップでめくり、左右にスワイプして前後のカードに移動できます。

> 補足: Service Workerはセキュリティ上の理由から `http://localhost` または `https://` での配信時のみ有効になります（`file://` で直接開いた場合は無効）。

## データの保存先

入力した文章はブラウザの `localStorage` に保存されます。サーバーには送信されません（翻訳時のみ、Google翻訳またはMyMemoryの翻訳APIへ英語文章を送信します）。

## 技術構成

- `index.html`: 画面構成（追加 / 一覧 / フラッシュカードの3タブ）
- `css/style.css`: スタイル
- `js/storage.js`: localStorageへの読み書き
- `js/translate.js`: 英日翻訳（Google翻訳エンジンを優先、MyMemory Translation APIにフォールバック）
- `js/speech.js`: Web Speech APIを使った読み上げ
- `js/app.js`: 画面の描画とイベント処理（スワイプ操作、Service Worker登録を含む）
- `manifest.json`: PWA用マニフェスト（ホーム画面追加時のアイコン・アプリ名など）
- `sw.js`: Service Worker（オフラインキャッシュ）
- `icons/`: アプリアイコン画像
